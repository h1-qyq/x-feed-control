# 安全边界与失败恢复

## 默认允许

- 读取当前 X 页面可见内容并做 20 条以上的匿名化计数。
- 切换 Home 的 Following/正在关注入口。
- 打开用户明确指定的已有 List。
- 在设置中定位控制项，但不提交新的静音、屏蔽或删除动作。

## 必须展示清单并最终确认

- 静音账号、静音字词、不感兴趣、屏蔽、隐藏主题。
- 删除或暂停任何历史/数据。
- 取消关注、取消订阅或批量关系变更。

## 永远禁止

- 批量自动取关。
- 自动点赞、回复、转发、关注或发帖。
- 读取密码、Cookie、令牌、localStorage、session store 或浏览历史。
- 因政治立场、观点差异或单纯高频出现判定低质量。

## UI 改版

使用可见文本、ARIA 角色、截图和设置搜索；尝试 Following/正在关注、Muted words/静音字词、Content preferences/内容偏好等语义同义词。不要使用固定坐标、旧 CSS 选择器或猜测菜单层级。

## 登录中断

如果 X 显示登录页，停止所有写操作，告诉用户在同一个浏览器自己登录，然后从检查点继续。不要绕过登录。
